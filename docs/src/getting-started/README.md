# Getting Started

Guides for connecting to Telcoin Network and building on it. Because the network is EVM-compatible, everything here uses standard Ethereum tooling; if you have built on Ethereum, the workflow will be familiar.

Start with [Reading Blockchain Data](reading-blockchain-data/README.md) to query the network using cURL, programmatic JSON-RPC requests, or client libraries. [Dapp Development](dapp-development/README.md) covers development tooling. [Faucet](faucet.md) explains how to get testnet TEL, and [Hardware Requirements](hardware-requirements.md) lists what is needed to run a node.
