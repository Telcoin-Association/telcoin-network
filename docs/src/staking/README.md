# Staking

How validator staking works on Telcoin Network. Membership is permissioned: governance issues a ConsensusNFT to approved operators, who stake TEL through the ConsensusRegistry contract and earn a share of each epoch's issuance for the consensus work they perform.

[How Staking Works](how-staking-works.md) covers stake versions, delegation, rewards, and the validator lifecycle. [Why Membership Model](why-membership-model.md) explains the reasoning behind permissioned membership. [How to Stake](how-to-stake.md) is the step-by-step operator guide, and [Future Direction](future-direction.md) discusses validator scalability limits and planned changes.
